# 🚀 NorthPeak Digital

A modern, responsive one-page agency website built as part of the **Digital Heroes Internship Qualification Task**.

The website showcases a fictional digital agency, **NorthPeak Digital**, featuring a clean UI, responsive layouts, semantic HTML, accessibility best practices, and optimized performance.

🔗 **Live Demo:** https://northpeak-digital-w94v.vercel.app/

🔗 **GitHub Repository:** https://github.com/Ayushhrajput/northpeak-digital

---

## 📌 Features

- 📱 Fully responsive design (360px, 768px, 1440px+)
- 🎨 Modern and professional agency UI
- 📌 Sticky navigation with smooth scrolling
- 💼 Services section with interactive cards
- 📊 Results section
- 💰 Pricing section with three plans
- 📧 Contact form with client-side validation
- ♿ Accessible and semantic HTML
- ⚡ Optimized for Lighthouse Performance & Accessibility
- ✨ Smooth hover effects and subtle animations

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/Ayushhrajput/northpeak-digital
```

Navigate to the project directory:

```bash
cd northpeak-digital
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
